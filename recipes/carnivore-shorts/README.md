# Carnivore Shorts Recipe Library

This folder contains concise, original recipe summaries derived from public carnivore/keto recipe videos indexed from YouTube. The purpose is to give the Blenheim price finder structured recipe data it can later use for meal-prep cards, ingredient searches, shopping-list generation and price comparisons.

## Files

- `recipes.json` — machine-readable recipe catalogue.
- `SOURCES.md` — source-video index and provenance notes.

## Classification policy

The local recipe version should match the site's strict carnivore-keto catalogue wherever practical:

- animal foods only;
- no flour, starch, potato, grains, fruit or vegetables;
- no sugar or syrup;
- plant seasonings, sauces and sweeteners from source recipes are removed or explicitly noted;
- sausages/bacon should be checked for sugar, starch and fillers;
- nutrition should be treated as an estimate unless exact product nutrition is available.

## Copyright / provenance

Ingredient concepts and cooking ideas are reorganised into original concise instructions for this project. Do not copy creator transcripts, captions or recipe prose verbatim into the app. Always preserve the source-video URL and creator attribution in the structured data.
